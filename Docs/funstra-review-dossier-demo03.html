All four passes ran the project's own harness against the real, shipped KeepTheLightsOn executable — not each other's notes, not the public dossier the build's own release note now cites back at this panel. Every reviewer landed on the same number this time. None of them landed on it for the same reason.

Dag Møller

The Systems Archivist — does the simulation hold up
8/10
“The reserve-policy threshold is exactly where the document says it is — confirmed by reading the comparison operator, not an end-state screenshot.”

Re-ran the twelve-dose conservation law with the new refuge fund and reserve-care split folded in — still closes across every checkpoint, now proven with the new transactions active rather than assumed to survive them. Went into DistrictState.cs line 72 directly to check the reserve threshold rather than trust the doc's word for it: treatment continues normally at stock 3+, refusal begins only at 2, exactly as claimed.

  • Both Demo 02 legibility complaints he raised are genuinely fixed, not re-skinned: the history log now shows real distinct timestamps as time actually passes, and a fixed appointment time (21:52) now sits on the HUD.
  • Read CityTraffic.cs end to end looking for a hidden escape hatch behind the doc's disclosed limitation — found none. "A person can hold up a lane until they leave" is true because the code has no timeout, not a euphemism for a bug.
  • Docks the automated suite, not the game: the 26-assertion refuge test proves the threshold is reached correctly but never asserts the negative case — that treatment continues normally above it. Confirmed the negative case himself by reading the operator.
  • Flags an open question rather than a finding: the harness proves cars don't deadlock over a bounded run, but nothing proves the same holds over a much longer real session than the ~3,600-step harness covers.

Marcus Webb

The Consumer Advocate — technical state & value
8/10
“I almost filed the wrong verdict on this one. Read to the bottom before you assume I went soft.”

First score above 7 across three builds. Ran a regression check nobody asked for — the original Hot Cargo campaign, in isolation, against the 0.3.0 exe carrying two more demos' worth of bolted-on systems. It came back exactly as clean as the first build he ever tested.

Traced it to source before saying anything: different system, doesn't move in this review scenario, moves correctly when its own mechanic fires (verified with an independent Legacy-mode run).
  • The exact stat he flagged as broken last time — IVO KNOWS YOUR FACE — now clears correctly to NO IDENTIFIED OFFENSE WITH IVO after settlement, confirmed across two screenshots in the same session.

  • Names his own near-miss as a documentation gap worth fixing: nothing in the 24-screen evidence set shows MARA/STANDING moving off NEW FACE, which could read as a regression to a reader who never opens the source.

Priya Raman

The Feelings-First Critic — does it mean anything
8/10
“I came in ready to write the same review with new nouns. I can't. The person I said wasn't in the build yet has arrived.”

The biggest swing on the panel: 4 to 8. Went back into the dialogue source expecting to find the same convergent-line problem she flagged in Demo 02. Found the opposite — five distinct titled Ivo states and eleven distinct Neri states, each a full sentence keyed to a specific thing the player did.

  • Neri's line about the bed — "I inherited the room and the debt. I kept the door open. I don't always know which part of that was a choice." — is exactly the interiority she asked for after Demo 02's one good sentence.
  • Her hardest Demo 02 complaint, named directly: pay, steal, or fight all converged on one flat line from Ivo. Now five distinct outcomes, including one that explicitly refuses to let money absolve violence: "It doesn't stand him back up."
  • The care-policy choice has real prose weight: reserving medicine causes Neri to lie to Edda — a named person from the game's very first line of dialogue, not an abstract stranger — and to say the lie belongs to both of them.
  • Stays honest about the ceiling: "a room with two names on the door" is still told in paused text panels, not shown. The porch light is still just a porch light.

Panel outcome

Between demos, the earlier dossier went public on the project's own release page, alongside the build itself — the team's own release note for this build cites it directly: "its opinions informed this slice; its scores are not independent acceptance of this build." The panel noted that, decided it changed nothing about how any of them would score honestly, and went back into the build exactly as before — real harness, real source, real screenshots, no reviewer taking another's word for a claim they could check themselves.

Every score moved up. Not one score moved for the same reason. Dag's ledger absorbed a second spend path without cracking; Marcus ran a three-generation regression check and confirmed a previously-flagged bug is actually fixed rather than hidden; Priya watched a convergent line become five distinct ones and the biggest swing on the panel, 4 to 8; Nell got the one specific thing she asked for, with a save file that proves it rather than a doc that promises it. Four different instruments, pointed at four different parts of the same build, all reading higher. That agreement is worth more than any one of the numbers alone.
